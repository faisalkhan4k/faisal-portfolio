# Mohammed Faisal Khan — Applied AI Engineer

A buildless static portfolio for GitHub Pages. The Pages workflow publishes the repository on pushes to `main`.

## Local preview

```bash
python -m http.server 4173
```

Open `http://localhost:4173`. Project tile data lives in `script.js`; replace each placeholder `url` with its app endpoint when ready. Update the LinkedIn and Devpost links in `index.html` when the profile URLs are available. The ocean video uses `ocean-poster.svg` as its fallback, including for visitors who prefer reduced motion.
