# Mohammed Faisal Khan — AI Engineer portfolio

Static portfolio focused on AI engineering, Voice AI, and reinforcement learning. Project cards open deep-linkable interview walkthroughs with architecture, experiments, lessons, demo steps, and next improvements.

## Local preview

```bash
python -m http.server 4173
```

Open `http://localhost:4173`. The site deploys to GitHub Pages through `.github/workflows/static.yml` on every push to `main`.
